BackBy helps you explore freely while staying aware of when you need to head back. Choose a return location, set when you need to arrive, pick your travel mode, and start an explore session. BackBy estimates your return time and reminds you when it may be time to turn back.

Use BackBy for lunchtime walks, casual bike rides, errands, sightseeing, or any trip where you want to wander a little without losing track of your return deadline.

## Features

- Set a return destination and arrival time
- Choose walking, cycling, driving, or transit
- Add an early-arrival buffer
- See your estimated return status during an active session
- Get turn-back reminders when it may be time to return
- Open Apple Maps when you are ready to navigate back
- No account required
- Optional Tip Jar to support development

BackBy uses location only during active sessions. Return estimates and alerts are best-effort and may depend on location accuracy, network availability, transit data, notification settings, and iOS background behavior.
